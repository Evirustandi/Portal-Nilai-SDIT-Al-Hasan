# SOP Harian Operator Website SDIT Al-Hasan

**Dokumen:** SOP Harian Operasional Website  
**Versi:** 1.0  
**Tanggal Efektif:** 27 April 2026  
**Pemilik Dokumen:** Tim Operator Sekolah

---

## 1) Tujuan
SOP ini digunakan untuk memastikan website sekolah selalu terbarui, akurat, aman, dan rapi setiap hari.

## 2) Ruang Lingkup
Mencakup pengelolaan konten di panel admin:
- Berita
- Galeri Foto
- Data Guru/Staf
- Program
- SPMB
- Nilai Siswa (jika diperlukan)

## 3) Peran
- **Operator Harian:** input/update konten harian.
- **Validator/Kepala TU:** cek final sebelum konten penting dipublikasikan.
- **Admin Sistem:** menangani akun user, akses, dan kendala teknis.

## 4) Jadwal Harian (Checklist)

### A. Pagi (07.00 - 08.00)
- [ ] Login panel admin.
- [ ] Cek pengumuman/agenda yang harus tayang hari ini.
- [ ] Cek berita paling atas (apakah masih relevan).
- [ ] Cek galeri beranda (gambar tampil normal).

### B. Siang (12.00 - 13.00)
- [ ] Upload dokumentasi kegiatan pagi (jika ada).
- [ ] Update status SPMB (jika ada pendaftar baru).
- [ ] Koreksi salah ketik/judul/tanggal konten.

### C. Sore (15.00 - 16.00)
- [ ] Final cek tampilan website publik (desktop + HP).
- [ ] Catat perubahan hari ini ke log audit.
- [ ] Backup/export data (minimal 1x per minggu atau setelah perubahan besar).

## 5) Standar Penulisan Konten
- Judul jelas, singkat, dan informatif.
- Gunakan tanggal yang benar (format konsisten).
- Hindari singkatan internal yang tidak dipahami orang tua.
- Gunakan bahasa sopan, resmi, dan mudah dipahami.
- Untuk berita: isi minimal 2 paragraf ringkas.

## 6) Standar Foto
- Foto harus relevan dengan kegiatan.
- Pastikan foto tidak blur/gelap.
- Hindari foto yang menampilkan data sensitif siswa.
- Isi caption yang deskriptif (contoh: "Kegiatan Literasi Kelas 3A").

## 7) Prosedur Publikasi Cepat
1. Input/edit data di menu terkait.
2. Klik simpan.
3. Reload website publik.
4. Pastikan konten tampil benar.
5. Catat di log audit (siapa, jam, dan perubahan).

## 8) Penanganan Error Umum
- **Konten tidak muncul:** refresh keras (Ctrl+Shift+R), cek ulang data di admin.
- **Foto tidak tampil:** cek URL foto dan izin akses file.
- **Jumlah data tidak sinkron:** cek status data (aktif/nonaktif) dan ulang simpan.
- **Tidak bisa login:** laporkan ke admin sistem untuk reset akun.

## 9) Kontrol Kualitas (Wajib)
Sebelum selesai shift:
- [ ] Tidak ada typo berat.
- [ ] Tidak ada tanggal salah.
- [ ] Tautan/WA/nomor kontak valid.
- [ ] Semua perubahan hari ini tercatat di log audit.

## 10) Persetujuan
Dokumen ini ditinjau setiap 3 bulan sekali atau saat ada perubahan alur kerja.
