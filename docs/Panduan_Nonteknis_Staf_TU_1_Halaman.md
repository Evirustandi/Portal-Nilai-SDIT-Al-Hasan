# Panduan Singkat Staf TU (Non-Teknis)

## Tujuan
Panduan ini membantu Staf TU mengelola informasi website sekolah tanpa istilah teknis.

## Yang Bisa Diperbarui Setiap Hari
1. **Berita**: kegiatan, pengumuman, prestasi.
2. **Galeri**: foto kegiatan terbaru.
3. **SPMB**: status pendaftaran siswa baru.
4. **Data Guru/Staf**: nama/jabatan jika ada perubahan.

## Langkah Praktis
1. Masuk ke panel admin.
2. Pilih menu sesuai kebutuhan (Berita/Galeri/SPMB/dll).
3. Klik tombol tambah atau edit.
4. Isi data dengan jelas.
5. Klik simpan.
6. Cek website publik untuk memastikan sudah tampil.

## Tips Aman dan Rapi
- Tulis judul yang jelas.
- Pastikan tanggal benar.
- Cek ejaan sebelum simpan.
- Jangan unggah foto yang tidak pantas atau terlalu pribadi.
- Jika ragu, minta validasi Kepala TU.

## Kapan Harus Lapor Admin Sistem
- Tidak bisa login.
- Tombol simpan tidak berfungsi.
- Data hilang/tidak muncul setelah disimpan.
- Ada tampilan website yang rusak.

## Penutup
Target utama: informasi sekolah selalu **benar, terbaru, dan mudah dipahami** oleh orang tua/siswa.
