File data.js berisi semua data konten (berita, galeri, guru, program, nilai siswa). Setelah diunduh, upload file ini ke hosting di folder data/ agar website terupdate.
📌 Langkah setelah download:
1. Buka GitHub → repository SDIT_Al-Hasan
2. Masuk ke folder data/
3. Klik file data.js → ikon pensil (edit)
4. Hapus semua isi lama → paste isi file baru → Commit
