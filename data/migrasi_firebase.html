Pindahkan data dari GitHub data.js langsung ke Firebase Firestore Anda.

Langkah 1: Masukkan Konfigurasi Firebase

Salin dari Firebase Console (Settings > General > Your Apps)

Langkah 2: URL Mentah (Raw) data.js GitHub

Contoh: https://raw.githubusercontent.com/username/repo/main/data.js

Langkah 3: Jalankan Migrasi
